#  Proyecto Sistema de Gestión - Biblioteca

Repositorio académico correspondiente al desarrollo de un sistema modular orientado a objetos en Java, implementando jerarquías de clases, estructuras de datos avanzadas (Listas, Sets y Maps) y gestión de fechas.

## 🗂️ Estructura del Paquete
Todas las clases del sistema se encuentran encapsuladas dentro del paquete correspondiente:
* **`biblioteca`**: Contiene la lógica del negocio, jerarquía geométrica y estructuras de almacenamiento.

### Clases Principales Implementadas:
* **Jerarquia de Socio:** `Socio`, `Docente`, `Estudiante`.
* **Colecciones y Estructuras:** Uso de `ArrayList`, `HashSet`, `LinkedHashSet`.
* **Manipulación de Fechas:** Gestión de plazos y cálculos temporales mediante la clase `Calendar`.
* **Generación de Reportes:** Construcción dinámica de textos formateados utilizando `StringBuilder` un metodo nuevo aprendido para 
que el encadenamiento de 'String' sea mas legible.

## 🛠️ Tecnologías y Entorno de Desarrollo
* **Lenguaje:** Java
* **IDE / Entorno:** BlueJ 
* **Control de Versiones:** Git & GitHub Desktop
